# 云盘媒体整理工具

在网盘网页里整理影视文件、补齐字幕，并在支持的网盘之间导入和导出 JSON 文件清单。

**当前版本 v3.0.48** · [安装脚本](https://raw.githubusercontent.com/Yanshov/cloud-media-organizer/main/cloud-media-organizer-v3.user.js) · [GitHub 发布页](https://github.com/Yanshov/cloud-media-organizer/releases)

| --- | --- | --- | --- |
| 导出和导入 JSON 清单 | 支持 | 支持 | 支持 |
| 识别影视、预览并整理文件 | — | 支持 | 支持 |
| 查找、补齐、导入和删除字幕 | — | 支持 | 支持 |

## 安装

1. 在桌面浏览器安装 Tampermonkey，然后打开上方的脚本链接。
2. 安装后刷新网盘页面，点击右下角的工具按钮。123 或光鸭若未识别到登录状态，切换一次文件夹。
3. 在工具的「设置」里配置 TMDB、字幕来源和可选的 AI 服务。

已安装的用户可打开脚本链接更新，原有浏览器配置会保留。

## 使用

- **跨盘清单**。在源网盘勾选文件或文件夹，导出 JSON。在目标网盘打开目的目录，选择文件或粘贴 JSON 后导入。从百度转光鸭时，可在百度选中原文件后点「导出光鸭清单」。当文件详情缺少指纹时，脚本会通过百度提供的下载地址分段读取原文件并计算 MD5、GCID 和 CID，消耗与下载原文件相当的流量。若光鸭导入提示缺少 GCID，可以在光鸭的「导入清单」中用本地原文件所在的文件夹生成清单，再尝试导入。清单只保存文件信息，导入成功取决于目标网盘能否通过文件哈希秒传。
- **影视整理**。配置 TMDB 后勾选视频或文件夹，点击「识别并检查」。在作品卡里核对片名、季集和字幕覆盖。剧名目录使用「剧名.年份」，季目录使用 `Season 01`、`Season 02` 等格式。从原文件名识别出的分辨率会写入视频和关联字幕名称。生成预览后核对原路径和目标路径，再点「确认执行」。需要处理缺字幕的视频时，可勾选「允许无字幕整理」。
- **清理文件**。选择清理规则后点击「识别并检查清理范围」。「仅空文件夹」会在回收前再次确认目录为空。按命名清理时会用 TMDB 识别作品，清单中的整文件夹包含全部内容。核对清单后再确认移入回收站。
- **补搬旧目录里的字幕**。在共同的上级目录勾选旧目录和视频所在目录，点击「识别并检查」，再生成整理预览。已就位的视频会略过，仍需改名或移动的已配对字幕会列入计划。预览会注明仍未配对的字幕。
- **查找字幕**。在缺字幕的电影或剧季卡内查找或导入字幕。剧季的自动候选须覆盖当前选区内的所有缺字幕集，才可确认补齐。默认使用迅雷，射手网和 OpenSubtitles 可按需配置。核对候选后再补齐。也可导入 SRT、ASS、SSA、VTT、ZIP 或 RAR。压缩包先读取目录，选择目标后逐份提取匹配字幕并检查正文，上传前再次核对正文摘要。上传保留来源文件名，核对上传后的内容，遇到同名文件时保留原文件。

字幕检查能识别可用的外挂字幕和 MKV 内嵌中文轨。作品卡上的「复查已有字幕」只检查该作品，检查结果不验证播放同步。启用可选 AI 后，文件名、目录名或少量字幕对白可发送给所选服务处理。

## 构建

使用 Node.js 20 或以上。源码在 `src/`，构建产物为 `cloud-media-organizer-v3.user.js`。

```sh
npm ci
npm run build
```

完整安装脚本会以可读的 JavaScript 格式生成。使用 `npm run format` 格式化源码，使用 `npm run format:check` 核对源码和安装脚本的格式。
