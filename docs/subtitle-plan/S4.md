### S4. SubDL 的名称搜索回退

- 位置：`subdlSearch`，仅用户已启用并配置时执行。
- 有可靠 TMDB 编号先按编号查询。没有编号时，在主名未取得可靠候选后，最多使用现有三个可信名称补查，并对查询与候选去重。
- 编号查询无结果可进入有限名称回退，但返回的作品必须重新核对身份；编号明确冲突不能被标题回退洗掉。
- 当前 API 文档中，字幕列表对应 `results` 的首部作品。实现前核对响应归属，不因列表中其他作品冲突而拒绝实际正确的整份结果，也不能把不同作品字幕混在一起。
- 保持整季包复用、分页与候选上限、ZIP 校验和准确集数匹配；授权或限流错误不通过换片名反复重试。
- 实施时核对官方文档 https://subdl.com/api-doc ，不顺带迁移 API 大版本。

## 验收

验收：编号优先与可信别名回退均可用；来源未配置不发请求；授权/限流不改名重试；响应作品归属正确；整季包、分页及 ZIP 校验保持。

共同保护：内嵌中文字幕算补齐；未启用来源不得请求；取消、授权中断、防覆盖和上传对账不能回归。交接时停止，不自动进入下一任务。
