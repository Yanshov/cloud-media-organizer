# 字幕优化：共同约束

## 用户已确认的规则

- 检测到内嵌中文字幕，算作已补齐，不再自动搜索外挂字幕。
- 目录覆盖状态与搜索状态分开；没有执行搜索不等于来源没有字幕。
- 迅雷是默认来源。SubDL 由用户启用并配置后补查。OpenSubtitles 默认关闭，只在用户主动启用后作为最后补充；不作为主路径或必需配置。
- 保留补齐的显式操作和删除预览确认，以及上传核验、防覆盖和结果不明的对账恢复。

## 接手先做

- 重读当前 `src/subtitles.js`、`src/subtitles-panel.js`、`src/works.js` 及相关测试。其他对话正在更新代码，本文行号只用于定位，不作为固定补丁依据。
- 任务生命周期、目录遍历等共享逻辑已实施。按实际调用阅读现有 API；不要默认读取完整共享逻辑工作清单。
- 本任务优化字幕业务，不重做界面布局、不另造任务或来源框架，不调用真实网盘写入进行验证。
- 先取得当前构建和测试基线，保留用户及其他对话的已有修改。

## 交接完成时必须报告

- 修改了哪些行为，实际请求数有什么变化，以及哪些原有保护仍有测试覆盖。
- 测试与构建结果、尚未验证的真实服务行为。
- 更新本文逐项执行状态；本清单本身不授权创建新分支、提交、推送或真实网盘写入。

- 每次仅实施索引分配的一个任务，完成后更新该任务文件与索引状态，报告结果后停止；不自动读取或执行下一任务。
- 阅读源码按符号和调用关系定位，不默认把整个源码目录、全部历史文档或未来阶段载入上下文。需要跨任务信息时只读取具体相关段落，并报告原因。
- 新增测试优先验证当前任务，交接前运行构建和完整回归。
