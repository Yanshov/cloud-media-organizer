# 云盘媒体整理工具

当前版本 **3.1.0**。支持百度、123、光鸭网盘的 JSON 清单导入导出，以及 123、光鸭的影视整理和字幕补齐。

[安装或更新脚本](https://raw.githubusercontent.com/Yanshov/cloud-media-organizer/main/cloud-media-organizer-v3.user.js) · [变更说明](CHANGELOG.md) · [开发与验证](docs/DEVELOPMENT.md)

## 安装

1. 在浏览器安装 Tampermonkey，打开上面的脚本链接并安装。
2. 只启用一份本工具。旧版“百度 / 123 / 光鸭 跨盘 JSON”使用不同脚本标识，升级后应停用旧版，避免重复拦截请求。
3. 刷新网盘网页，打开右下角工具按钮。光鸭和 123 若尚未捕获登录状态，切换一次文件夹。

为直接更新已有 v3 草稿，脚本保留原来的 `@name` 和 `@namespace`；以 `@version 3.1.0` 和工具面板版本为准。密钥在浏览器脚本设置中填写，不写入源码或仓库。

## 功能范围

| 功能 | 百度 | 123 | 光鸭 |
| --- | --- | --- | --- |
| 勾选文件/文件夹并递归导出 JSON | 支持 | 支持 | 支持 |
| 粘贴或选择 JSON 导入当前目录 | 支持，受秒传接口限制 | 支持 | 支持 |
| 影视识别、季集确认、预览后整理 | — | 支持 | 支持 |
| 字幕搜索、选择、下载、上传后核验 | — | 支持 | 支持 |
| 新版导入核验后清理对应旧版 | — | — | 支持，执行前显示预览 |

**跨盘清单不是文件内容。** 秒传仅在目标网盘命中相应哈希时成立；未命中会报告未完成。百度超过 256 KB 的文件需要清单没有提供的分片哈希，因此不会伪报导入成功。脚本读取网盘已有的 MD5/GCID/CID，不下载整个视频来计算这些值。

## 使用

### 跨盘清单

在网页勾选范围，点击“导出 JSON”；在目标网盘打开目标文件夹，粘贴清单后点击“导入 JSON”，或选择清单文件。目标目录会固定为本次任务开始时的位置。

同名文件不会直接覆盖。光鸭“导入新版，成功后删除对应旧版”会先展示预览，核验新版后再清理相应旧版。任务进行时可以点击“停止当前任务”；正在进行的请求结束后，后续请求停止。已提交但未确认的操作应先刷新目录核对。

### 影视整理

在 123 或光鸭勾选视频或文件夹，填写 TMDB API Key/Read Access Token，识别作品并核对电影、剧集、季集和目标路径，然后预览、执行。可选 AI 识别会发送文件名和所在目录名给配置的服务，默认不开启。字幕与关联附件随视频整理；清理功能会单独展示范围。

### 字幕补齐

1. 在字幕设置填写 Assrt Token，按需启用 OpenSubtitles、射手。射手使用视频四段哈希匹配，需要网盘允许分段读取。
2. 勾选视频或文件夹，读取并检查已有字幕，再查找。
3. 优先选择简中双语、繁中双语，其次简体中文、繁体中文；显示来源的真实文件名。
4. “只看待选择”只显示需要手动选择的项目。作品或季集不能确认时不会自动上传。
5. 点击补齐，检查字幕格式与中文正文、上传，并在网盘核验。待核验项目先点“重新检查目录”，不要重复上传。

搜索片名不附加发行年份；年份仍用于结果核对。整季资源会复用文件列表，但每集都重新检查作品和季集。Assrt 限流等待可停止；已有冷却不会逐个消耗候选。网盘授权失败会中断并提示重新登录、检查目录。

## 源码与备份

- `cloud-media-organizer-v3.user.js`：可直接安装的完整脚本。
- `src/`：9 个源码模块及构建顺序，修改这里。
- `scripts/`：构建和测试入口，不依赖第三方 npm 包。
- `tests/`：模拟 API/DOM 和可重现的测试样例，不包含登录凭证或第三方字幕正文。

```sh
npm run build
npm test
```

Node.js 20 或以上即可。GitHub Actions 在每次提交时执行检查；下载仓库 ZIP 或 `git clone` 可恢复源码、成品和测试。

本版将 v3 草稿未迁移的功能接回，并恢复此前已验证的字幕修复。没有宣称固定成功率、内存占用或加速比例。本地测试不代表已在你的真实网盘执行过上传，接口可用性、登录状态和字幕库收录仍以实际日志为准。
