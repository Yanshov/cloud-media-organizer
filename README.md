# 云盘媒体整理工具

在网盘网页里整理影视文件、补齐字幕，并在支持的网盘之间导入和导出 JSON 文件清单。

| --- | --- | --- | --- |

| 识别影视、预览并整理文件 | — | 支持 | 支持 |

## 安装

1. 在桌面浏览器安装 Tampermonkey，然后打开上方的脚本链接。
2. 安装后刷新网盘页面，点击右下角的工具按钮。123 或光鸭若未识别到登录状态，切换一次文件夹。
3. 在工具的「设置」里配置 TMDB、字幕来源和可选的 AI 服务。

如果已安装版本号高于 3.0.1 的构建，请打开脚本链接手动安装。脚本沿用原有的安装标识和浏览器配置。

## 使用

- **跨盘清单**。在源网盘勾选文件或文件夹，导出 JSON。在目标网盘打开目的目录，选择文件或粘贴 JSON 后导入。清单只保存文件信息，导入成功取决于目标网盘能否通过文件哈希秒传。
- **影视整理**。配置 TMDB 后勾选视频或文件夹，点击「识别并预览」。可在作品卡里修正片名或季集。核对原路径和目标路径后，再点「确认执行」。
- **清理文件**。直接点击「清理文件」下的「识别并检查清理范围」。按命名清理时会用 TMDB 识别作品。核对清单后再确认移入回收站，整文件夹条目包含其中的全部内容。
- **查找字幕**。工具会检查已选范围，只搜索确认缺字幕的项目。默认使用迅雷，SubDL 和 OpenSubtitles 可按需配置。核对候选后再补齐。也可导入 SRT、ASS、SSA、VTT 或 ZIP。上传保留来源文件名，核对上传后的内容，遇到同名文件时保留原文件。

字幕检查能识别可用的外挂字幕和 MKV 内嵌中文轨。作品卡上的「重新检测」只检查该作品，检查结果不验证播放同步。启用可选 AI 后，文件名、目录名或少量字幕对白可发送给所选服务处理。

## 构建和测试

使用 Node.js 20 或以上。源码在 `src/`，构建产物为 `cloud-media-organizer-v3.user.js`。

```sh
node scripts/build.cjs
node scripts/test.cjs
```

测试使用模拟接口和合成字幕样例，不会写入真实网盘。
